Neural Collaborative Filtering

推薦システムでは、ユーザーの好みを予測するために協調フィルタリング（似た嗜好を持つ人の行動履歴から好みを予測する手法）がよく使われます。しかし、従来の数式モデルではユーザーと商品の間の複雑な好みの関係性を捉えきれない問題がありました。この論文では、ニューラルネットワーク（人間の脳の神経回路を模した計算モデル）を活用した「Neural Collaborative Filtering」という仕組みを提案しています。直線的な関係だけでなく非線形（単純な比例関係では表せない複雑な変化）な関係も学習できるよう、多層のネットワークを組み合わせています。映画やECサイトのデータを用いた実験の結果、従来の代表的な推薦手法よりも高い精度でユーザーが興味を持つアイテムを予測できました。

DeepReID: Deep Filter Pairing Neural Network for Person Re-identification

複数の防犯カメラに映った映像の中から、同じ人物を同一人物だと見分ける人物再識別という課題があります。カメラごとに照明の明るさや撮影角度、歩く人の姿勢が異なるため、正確に見分けることが困難でした。この論文では、ディープラーニング（多層のニューラルネットワークを用いた深層学習技術）を使って、画像のズレや変形に対応する「フィルターペアリングニューラルネットワーク」を提案しています。画像の部分ごとの特徴を比較し、多少の位置のズレがあっても同一の特徴として捉える仕組みを備えています。大規模な人物画像データセットで検証した結果、従来の手作業で特徴を抽出する手法に比べて人物の照合精度が大きく向上しました。

EEGNet: a compact convolutional neural network for EEG-based brain–computer interfaces

頭皮から測定される脳波（脳の電気的な活動信号）をコンピュータの入力として利用する技術があります。従来は脳波の種類ごとに解析するプログラムを手作業で作り分ける必要があり、幅広い用途で使いにくいという課題がありました。そこで著者らは、構造を軽量にしたCNN（画像を格子状に処理するニューラルネットワーク）である「EEGNet」を提案しました。脳波の時間的な変化と電極の位置関係という2つの特徴を、少ない計算量で効率的に捉えられるよう工夫されています。実験の結果、運動をイメージしたときの脳波や視覚に反応した脳波など、異なる種類の脳波タスクにおいて従来の手法と同等以上の高い認識精度を達成しました。

Pyramid Vision Transformer: A Versatile Backbone for Dense Prediction without Convolutions

自然言語処理で広く使われるTransformer（文中の単語同士の関係性を全体的に把握する仕組み）を画像向けに応用した技術が登場しましたが、物体の位置を細かく特定するタスクには不向きでした。画像全体を一括で大まかに分類することに特化しており、ピクセル単位での詳細な予測に必要な高解像度の情報をうまく扱えなかったためです。本論文では、畳み込み（画像を格子状に処理する演算）を一切使わずに、画像の解像度を段階的に小さくしながら特徴を抽出する「Pyramid Vision Transformer」を提案しました。ピラミッドのように異なる縮尺の特徴を同時に作成することで、細かい位置情報も保持できるようにしています。物体検出（画像内の物体の位置と種類を見つけるタスク）などの実験において、従来の畳み込みベースのモデルを上回る認識精度を達成しました。

The Graph Neural Network Model

従来のニューラルネットワーク（人間の脳の神経回路を模した計算モデル）は、格子状の画像や表データのような規則的なデータしかうまく扱えませんでした。しかし、化学の分子構造や人と人とのつながりのように、要素同士が不規則に結びつくグラフ構造（点とそれを結ぶ線で表されるデータ）を直接扱うことが求められていました。そこで本論文では、グラフの構造をそのまま入力として受け取れる「Graph Neural Network」というモデルを提案しました。結ばれた点同士の間で情報を互いに伝達し合うことで、全体のネットワークの性質や各点の役割を学習します。化学分子の性質予測などの実験において、従来のグラフ解析手法や単純なネットワークよりも高い精度で予測できることを示しました。

Real-Time Single Image and Video Super-Resolution Using an Efficient Sub-Pixel Convolutional Neural Network

粗くてぼやけた低解像度の画像から、細部まで鮮明な高解像度画像を復元する超解像という技術があります。従来の深層学習手法は入力画像を前もって大きく引き伸ばしてから処理していたため、計算量が非常に多くなり、動画などのリアルタイム処理が困難でした。この論文では、計算の大部分を低解像度のまま行い、最後の層でピクセルを並べ替えて一気に拡大するサブピクセル畳み込み（小さな画像の特徴を再配置して高解像度化する手法）を提案しました。これにより、画質を保ちながら無駄な計算を大幅に削減することができます。実験の結果、従来モデルと同等の高い画質を維持しながら計算速度を飛躍的に高め、動画を毎秒多数のフレームでリアルタイムに超解像処理することに成功しました。

Accelerating the Super-Resolution Convolutional Neural Network

CNN（画像を格子状に処理するニューラルネットワーク）を用いた画像の超解像（粗い画像をきれいに拡大する技術）は高い画質を達成していましたが、計算が重く動画のようなリアルタイム処理ができませんでした。この論文では、処理速度を劇的に高速化するために「FSRCNN」という新しいネットワーク構造を提案しました。従来のように最初に入力画像を拡大するのではなく、低解像度のまま計算を行い、さらに中間層で情報量を一時的に絞り込む砂時計のような構造を採用しています。そして画像の拡大処理は、最後の層で逆畳み込み（小さくなったデータを元のサイズ以上に広げる処理）を用いて一度だけ行います。実験の結果、従来の超解像モデルよりも画質を向上させながら、計算速度を数十倍に加速してリアルタイムでの処理を達成しました。

Neural network-based face detection

任意の写真の中から、大きさや向き、照明の当たり方が異なる人間の顔を正確に見つけ出す顔検出という課題があります。背景の模様などを誤って顔だと判定してしまう「誤検出」を抑えつつ、様々なバリエーションの顔を見逃さずに見つけることが困難でした。この研究では、画像を小さく切り取った領域を入力とし、顔か顔でないかを自動判定するニューラルネットワーク（人間の脳の神経回路を模した計算モデル）を構築しました。さらに、複数のネットワークの判定を組み合わせるアンサンブル学習（複数のモデルの予測を統合して精度を上げる手法）や、誤判定した領域を再度学習させる仕組みを導入しました。多様な顔が含まれる複雑な写真のデータセットを用いた実験において、顔の見逃しを減らしながら誤検出も大幅に抑えた高精度な検出に成功しました。

Revisiting Deep Learning Models for Tabular Data

A Survey of Quantization Methods for Efficient Neural Network Inference

この論文は、深層学習モデルの計算を軽くしてスマートフォンなどの小型機器で動かすための技術である「量子化」について体系的にまとめた解説論文です。深層学習モデルは通常、細かな小数（32ビット浮動小数点数）を使って計算を行いますが、これは多くのメモリと電力を消費します。量子化とは、これらの数値をより少ないビット数（例えば8ビットや4ビットの整数）に圧縮して計算を高速化する手法です。本論文では、モデルの学習後に数値を丸める手法や、量子化による誤差を想定しながら学習を進める手法など、多様な技術の長所と短所を網羅的に分類しました。その結果、目的に応じてどの量子化手法を選べば、予測精度を保ちつつメモリ消費や推論時間を削減できるかの指針を示しました。
